# ReSet Pod

**Rest. Reset. Rise.**

ReSet Pod is a wellness-focused digital experience designed for rest stop environments. It provides travelers with structured, short-duration recovery sessions including power naps, meditation, yoga, and resistance training.

---

##  Overview

ReSet Pod is built to enhance the travel experience by offering a private, comfortable, and restorative environment. This project demonstrates a modern, user-friendly interface for selecting and experiencing guided recovery sessions.

---

## ⚡ Features

* Interactive session selection (10–30 minutes)
* Built-in countdown timer for each session
* Clean, professional UI designed for real-world deployment
* Mobile-friendly layout
* Smooth user experience with instant feedback

---

## Session Types

* **10 minutes** — Perfect for power nap
* **15 minutes** — Great for mindful meditation
* **20 minutes** — Great for yoga
* **25 minutes** — Great for resistance training workout
* **30 minutes** — Great for complete relaxation

---

## What’s Inside the Pod

* Charging ports
* Climate-controlled environment
* Adjustable lighting and sound
* Quick workout and resistance training
* Yoga and meditation support
* Privacy and security
* UV sanitation system
